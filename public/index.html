06 / LAYOUT & USAGE

A consistent grid and content rhythm keeps product pages clear and scannable.

01

Confident clarity

Use direct language, visible hierarchy, and specific outcomes. Avoid vague financial claims or unexplained jargon.

02

Focused action

One primary action per region. Indigo is reserved for the main action; alternatives stay quieter.

03

Color with purpose

Use coral sparingly. Keep primary content unframed; avoid nested cards and decorative panels.

07 / GOVERNANCE

Use & contribution policy

Review these checks before adding a token or handing off a component.

Token use

Prefer semantic and component variables over hard-coded color, spacing, and radius values. Propose a token before adding a recurring one-off value.

Accessibility

Maintain WCAG AA contrast, visible keyboard focus, logical heading order, and status cues that pair color with text or icon.

Responsive QA

Verify reflow at 1100 px and 760 px, test component states, confirm labels and error copy, and check all values resolve to named tokens.
